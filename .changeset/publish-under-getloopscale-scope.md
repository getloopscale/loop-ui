The package is published as `@getloopscale/ui`.

0.37.0 named the package under a scope this project does not own on npm, so that version was never
published. Install `@getloopscale/ui` and import from it; everything else 0.37.0 describes stands,
including the `--loopscale-control-*` variables and the `loopscaleUIPreset` export.
